## Como a pasta está organizada

- Cada bloco do AVA virou uma pasta numerada, e cada seção é um arquivo `.md`, na ordem do AVA. Os arquivos da plataforma (slides, modelo de documentação, projetos Astah de exemplo) ficam em `arquivos/`, fora do git.
- `notas.md`: notas, prazos e situação de cada entrega (fora do git).
- `avisos.md`: mural de avisos.
- `_bruto/`: o conteúdo original capturado do AVA, para referência (fora do git).
