# Projeto EXEMPLO

**Viajando.Com**: Projeto Exemplo de uma Agência de Viagens

**Contextualização**:

Uma agência de turismo pretende lançar um aplicativo focado em atrair novos clientes por meio das experiências de viajantes que já utilizam seus serviços. A proposta é que esses usuários compartilhem seus roteiros para ajudar outras pessoas a planejarem suas próprias viagens. Para impulsionar a demanda já na próxima temporada de férias, a empresa iniciará uma campanha publicitária em curto prazo, ocasião em que pretende apresentar uma versão inicial do aplicativo com algumas funcionalidades básicas de consulta e compartilhamento de roteiros selecionados.

Em uma proposta inicial para o aplicativo, para Android, a agência tem o propósito de dispor funcionalidades para possibilitar os viajantes divulgarem suas viagens. Nessa versão inicial é necessário que o viajante possa cadastra uma viagem, com uma breve descrição turística do destino. O viajante deve poder vincular a viagem a um ou mais roteiros visitados, para os quais podem ser catalogados os pontos de interesse, com informações, itinerários, mapas, fotografias, vídeos ou outros documentos. Os viajantes interessados (clientes) podem consultar essas viagens e acessar esses catálogos, com opções de filtros por destinos, roteiros ou pontos de interesse. Paralelamente, é um requisito indispensável para a agência a integração em um painel gerencial (dashboard, acessado via web) que apresente dados das viagens e roteiros cadastrados, assim como informações de consultas realizadas, visando extrair informações estratégicas sobre destinos e tendências de interesse dos viajantes para direcionar ações da agência.
